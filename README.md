# adafmt.com

Static one-page product introduction site for Adafmt™ with an “In the Lab” validation section.

## Contents

- `index.html` — landing page.
- `assets/styles.css` — site styling.
- `assets/logo.svg`, `assets/hero.svg`, `assets/validation.svg`, `assets/favicon.svg` — visual assets.
- `robots.txt`, `sitemap.xml`, `llms.txt` — search and AI discovery support.
- `CNAME` — GitHub Pages custom domain configuration for `adafmt.com`.
- `typst/site-brief.typ` — source planning brief.

## Publishing

Enable GitHub Pages for this repository, publish from the selected branch, and configure the custom domain as `adafmt.com`.

## Trademark convention

Use `Adafmt™` for the first prominent product reference, `Adafmt` for later prose, and `adafmt` for the command-line tool.

## Current proof points

- Relevant ACATS Ada 2012 tests.
- Supplemental Ada 2022 feature tests.
- Real-world open-source Ada corpus.
- Largest test corpus contains 51,000+ Ada files.
- Recorded ACATS run metrics are shown on the page.
