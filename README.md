# Adafmt.com Static Site

Static one-page product introduction site for **Adafmt™**, the professional Ada formatter.

## Contents

- `index.html` — single-page landing site
- `assets/styles.css` — site styling
- `assets/logo.svg` — Adafmt wordmark
- `assets/hero.svg` — product workflow illustration
- `assets/validation.svg` — In the Lab dashboard illustration
- `assets/favicon.svg` — favicon
- `robots.txt` — crawler rules
- `sitemap.xml` — sitemap for search engines
- `llms.txt` — AI/search summary
- `CNAME` — GitHub Pages custom domain
- `typst/site-brief.typ` — durable content/design brief

## Messaging rules

- Use **Adafmt™** on first prominent product mention.
- Use **Adafmt** for later product prose.
- Use `adafmt` for the command, code, configuration, and file paths.

## Current launch posture

This site is an initial product introduction page. Adafmt v1.0.0 for Linux amd64 and Linux arm64 is planned by June 1, 2026. A Windows 11 release is expected shortly afterwards. macOS is supported, but release packaging depends on resolving an issue with an external vendor library. Trial builds are planned after licensing is enabled. The planned trial is 14 days, with an option to subscribe at the end of the trial period.

Fresh small, medium, and large benchmark results are intentionally marked as coming soon.
